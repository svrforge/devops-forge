# Privacy

Pipeline Doctor runs on your own computer. It reads the pipeline files you point it at and writes a report.

- It does not collect, store or send any data.
- It makes no network calls and contains no analytics.
- It redacts secrets from its reports.

When you use it as a skill, your coding agent reads the report and may read the same files, under that agent's own privacy terms.
